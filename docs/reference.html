swarm-ext configuration agents.launch.defaultTarget

Where the per-harness "Agents: New <Harness>" commands run. Device choice stays with the CLI: 'auto' emits --device auto, which draws from the fleet's worker pool (agents devices role). The (Pick Host), (Auto), (Pick Project), (Pick Account), and (Local) command variants are unaffected.

Options

FlagsDescriptionChoicesDefault
string—auto, local, ask"auto"

Notes

Choices: auto: Let the CLI pick a device (`--device auto`). Once you mark devices with `agents devices role <name> worker`, new agents rotate over those workers only.; local: Always run on this machine.; ask: Prompt for the host on every launch.
