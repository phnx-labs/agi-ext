What the evidence says

Six findings that shape the design

  • Your shot

    The Explorer occupies the right side today and you barely use it. That is free space for the project.

  • Menu rec.

    AGI Menu's cycle bar is mostly 23 Duplicate. Duplicates are closed work counted as open; the bar should show only Doing / In review / Todo.

  • Menu rec.

    In the 3:10 PM recording an expanded PR group repeats the same docs/reference-pages → main chip row about 20 times. Expanded detail needs one row per PR.

  • Ranker

    linear tasks --similar answers in about 1 s, but returns Done and Canceled tickets, and its top hit is the tab's own ticket. Up next must filter to open work and show the tab's ticket separately.

  • Linear

    AGI's six milestones were all due in August, and none of the 33 open tickets has a milestone. A milestone-first panel would be empty for this project; it must say so plainly.

  • Latency

    projects status takes 14 s (fleet fan-out), projects prs list 7 s. Three clients each doing this, and each joining tickets to PRs to sessions their own way, is the drift you want gone.

The pick

Build F: native sections, with the best part of each

FROM BReal VS Code view sections.

Each panel is its own collapsible, reorderable view in the right container, toggled from the container's menu. You get I7 from the editor itself, with no settings page to build.

FROM CUp next follows the focused tab.

The tab's own ticket is pinned on top, then open tickets ranked by similarity to it. With no agent tab focused it falls back to the cycle's priority order.

FROM DOne row per piece of work.

A ticket row carries its PR's state and its session's dot. You see "ready to merge" or "agent idle" without opening a second panel.

FROM AThe Menu's visual language.

Cycle bar with legend (duplicates removed), PR status ring that turns into a check, compact rows that expand inline, merge pinned to the head commit.

FROM EMilestones, but honest.

The Overview shows the current milestone if one exists, and says "no current milestone, 33 open tickets unplanned" when it doesn't.

LEFT OUTA Kanban board and a Needs-you band.

Lanes don't fit 340 px. Needs-you already lives on the left (Active Terminal) and in the Fleet list; the right side shows a session's state only next to its ticket.

Plan

One engine in the CLI, two renderers

Every join and ranking you see above moves into one CLI verb. AGI Menu (Swift) and AGI EXT (webview) only draw it. The daemon keeps it warm and pushes changes on the stream both apps already read, so opening the panel is instant instead of 14 s.

# one read, both apps
agents projects home agi --json [--focus <session-id>]

# pushed on change (EXT already reads this stream)
agents feed watch --json   # scope: project.home
{
  "project": { "name": "agi", "linear": "AGI" },
  "cycle":   { "number": 32, "endsAt": "2026-10-13",
               "byState": { "Doing": 12, "In Review": 0,
                            "Todo": 15, "Backlog": 6 } },
               // closed states (Duplicate, Canceled) excluded
  "milestone": null,  "unplanned": 33,
  "upNext": { "focus": "PHNX-4227",
              "items": [ /* open only, ranked */ ] },
  "work": [ { "ticket": "PHNX-4227", "state": "Doing",
              "pr": { "repo": "phnx-labs/agi-cli", "number": 3835,
                      "ci": "SUCCESS", "ready": true,
                      "headSha": "…" },
              "sessions": [ { "id": "…", "phase": "idle" } ] } ],
  "unticketedPrs": [ … ],
  "generatedAt": "…", "partial": false
}
  1. CLI: agents projects home

    Join tickets, PRs and sessions; rank Up next with the Linear ranker, filtered to open work; drop closed states from the cycle counts. The daemon caches it per project and emits on change.

    Done when: Swift's HomeModel join and EXT's tasks.ts join have one test suite that pins this output; warm read under 200 ms.
  2. AGI Menu Home renders the verb

    Delete the Swift join and ranking; keep the views. Fix the repeated chip row while there.

    Done when: Menu Home shows identical counts to the verb for the same project, and the duplicate-row bug is gone in a recording.
  3. AGI EXT right container, option F

    Rewrite the current branch (three plain list views) into F's sections on top of the verb: Overview, Up next, Work, Pull requests, Sessions. Each is a separate view you can hide.

    Done when: on zion, switching editor tabs re-ranks Up next within a second, and a PR going green animates in place.
  4. Retire what F replaces

    Fold the Fleet dashboard's backlog into the Work view, then remove it once you've used F for a week.

    Done when: you agree nothing in Factory/Fleet backlog is missed.
